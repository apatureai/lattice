APATURE UI GRAPH - VISUAL PERCEPTION LAYER

A compact scene graph for design-aware agents and judges.
UI Graph is the shared representation layer for rendered product UI. It combines capture artifacts, accessibility and DOM structure, computed styles, screenshot evidence, and UI DNA into graph-backed prompt views. The goal is fewer tokens, better element grounding, and more specific agent repair loops.

Graph builder

Normalize, merge, reference, project

  • Build visible nodes from DOM geometry, accessibility roles, text, computed styles, and screenshot metadata.
  • Add edges for containment, alignment, proximity, label/control relations, reading order, and component-family similarity.
  • Project UI-DNA rules onto nodes and regions, then attach evidence refs instead of stuffing every image into the prompt.

Graph output

UIGraphSnapshot

  • Nodes: role, label, text, rect, affordances, computed visual facts, design-token matches, and confidence.
  • Edges: contains, adjacent_to, aligned_with, labels, controls, flows_to, visually_groups.
  • Violations: UI-DNA drift with refs, route, viewport, evidence, and confidence.

Prompt views

Small context, useful evidence

  • summary for page structure; violationsOnly for Gate; focus for a graph neighborhood.
  • actionMap for affordance awareness; patchHints for coding-agent repair loops.
  • Full screenshots stay behind refs unless ambiguity demands visual evidence.

Research conclusion

Not another browser agent

  • Playwright MCP already has structured accessibility snapshots.
  • Stagehand and Browserbase already have natural-language browser primitives and caching.
  • OmniParser proves screenshot-to-structure is a real substrate.
Apature's wedge is the UI-DNA-aware representation that feeds neutral design judgment and repair loops.
Hard boundary

Perception only

  • No browser actions.
  • No code edits.
  • No GitHub publishing.
  • No replacement for judgment-engine or UI DNA.
